
# Lesson Recapper – Project Management Lab

## Project Overview

Lesson Recapper is an AI-powered web application developed as part of our Ironhack AI Bootcamp. The application converts lengthy lecture and meeting transcripts into approximately five-minute audio summaries highlighting five key points, allowing users to review important information while on the go.

## Purpose of This Lab

This lab examines how our classroom project could be developed into a client-ready application by identifying key stakeholders, evaluating production requirements, and revising the original project scope.

## Repository Structure

- **README.md** – Project overview, lab objectives, and repository structure.
- **lesson-recapper-project-analysis.md** – Contains the four parts of the project management assignment:
  1. Project Snapshot
  2. Stakeholder Impact Analysis
  3. From Demo to Real Project
  4. Revision Brief

## Project Context

This repository contains the project management analysis of Lesson Recapper, not the application's source code. The analysis is based on our team's bootcamp project and considers the additional requirements for a potential real-world deployment.
